# 大模型回答

提示词拼好之后，由本机的 `models/Qwen2.5-3B` 从 `Answer:` 往后生成。实现在 `src/generate.py` 的 `Generator`。`scripts/run_baseline.py` 每个数据集加载一次模型，再对每一轮调用 `generate`。`--retrieve_only` 打开时不加载模型。

## 怎么生成

模型以 `float16` 放在 `--device` 指定的 GPU 上，默认 `cuda`。分词器用这个目录里的 tokenizer。没有 pad token 时，用 eos token 代替。

生成是贪心的：`temperature` 固定为 0，不采样。新写的 token 最多 `--max_new_tokens` 个，默认 128。提示词本身的 token 不计入这 128。

解码时只取新生成的 token，不把提示词再抄一遍。然后去掉首尾空白，只留第一段：遇到空行就截断。基座模型有时会在答案后面继续写，第一段是为了留下直接回答的那一句。

这一轮的生成结果写在结果 jsonl 的 `prediction`。同文件里的 `gold_answer` 是数据里的标准答案，用来对照，不参与生成。

## 改哪里

换模型目录用 `--llm_model`，默认 `models/Qwen2.5-3B`。换生成长度用 `--max_new_tokens`。

贪心、只留第一段、float16，都在 `Generator.generate` 和 `Generator.__init__`。提示词的内容在 `build_prompt`，见 [../上下文构造/上下文构造.md](../上下文构造/上下文构造.md)。
